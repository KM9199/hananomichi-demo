iCloud Driveから開く手順・不完全な場合

PCでこのindex.htmlをiCloud Driveへコピーし、同期後、iPhoneの「ファイル」→「iCloud Drive」から開きます。プレビューはSafariとは異なる場合があります。「JavaScript：動作中」が出るか、花／資が切り替わるか、最近使用が左右に動くかを確認してください。表示されない・操作できない場合はファイル表示側の制限の可能性もあるため、SafariでHTTPS公開URLを開いて再確認します。

GitHub Pagesの場合は、デモ専用リポジトリの直下にこのindex.htmlだけをアップロードし、Settings → Pages → Deploy from a branch → main / (root) → Saveです。表示されたHTTPSの公開URLをSafariで開きます。既存サイトを上書きしないでください。公開は今回は行っていません。

実機での確認順序
  1. Safariのページ拡大率を100%にし、縦向きで開きます。
  2. 基本見本の1行目の品名・数・単価を押し、×とパネル外で閉じます。
  3. 品名パネルで最近使用を左右、一覧を上下へ動かします。右側ジャンプ・下部2ボタンが一緒に動かないか確認します。
  4. ア〜ワを押して目的の商品へ移るか、隣を誤って押さないか、44pxの商品行を押しやすいか確認します。
  5. 各桁の見本、PayPay別会計、前後・新規の固定見本を試します。数量・単価の確定時に計算します。決済は表示切替のみです。
  6. 横向きとSafariのバー表示／非表示も試します。短い画面はページ全体を上下に動かして下部へ進みます。

表示を切り替えて配置を確認できます。品名・数量・単価の欄からもパネルを表示できます。×またはパネル外で閉じます。品名一覧はスクロールと五十音ジャンプを確認できます。

商品名・読み・日付・金額は仮データです。数量または単価→数量→単価の3タップで編集し、明細金額・総数量・会計合計を再計算します。途中の×・外側・Escapeは両値とも取消です。再読み込み・会計の見本切替では初期値に戻ります。品名編集・直接入力・永続保存・実会計作成・CSV出力・Access連携は未実装です。前後ボタンは固定見本を切り替えます。

  • 最近使用は丸い花／資切替と可変幅の横1行です。
